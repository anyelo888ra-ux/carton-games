# 🎨 carton-Games Arcade & Studio Hub

[![Status Active](https://img.shields.io/badge/Status-Active-brightgreen.svg)](#)
[![Ruffle WASM](https://img.shields.io/badge/Flash_Emulator-Ruffle_WASM-blue.svg)](#)

**carton-Games** es un portal web de preservación de minijuegos retro y lanzador para herramientas de romhacking y speedrunning de Super Mario 64.

---

## 🚀 Características

- 🎮 **Emulación Flash (Ruffle WASM):** Ejecución de minijuegos en formato `.swf` sin necesidad de plugins externos.
- 🛠️ **Integración de Editor 64:** Enlace directo al estudio de desarrollo de niveles (`https://sm64.editor-64.duckdns.org/`).
- ⏱️ **Integración de TAS Speedrun 64:** Acceso directo a la suite de telemetría y física (`https://tas.speedrun-64.duckdns.org/`).
- 🎨 **Diseño Toon Retro:** Interfaz ligera, responsiva y adaptable a móviles y PC con Tailwind CSS.
